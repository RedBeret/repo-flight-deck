# Repo Flight Deck Plan

## Product Positioning

Build a polished internal engineering dashboard that helps a lead or maintainer answer a simple question: which repos are safe to ship, and which ones need attention now?

## Core User Story

An engineering lead needs one place to see:

1. Which repositories are trending risky
2. Which pull requests are close to merge but blocked
3. Where CI and security work is piling up
4. Whether a release is actually ready

## Why This Project Fits The Portfolio

This complements the other portfolio projects by moving away from devices and replay into software team operations:

- developer experience
- release management
- CI and security visibility
- practical web app product design

## MVP Scope

- repo catalog and selected repo workspace
- CI checks summary and timeline
- pull request board with risk score
- security alerts panel
- release-readiness checklist and export packet
